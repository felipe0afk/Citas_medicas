# 🏥 Sistema de Gestión de Citas Médicas (FastAPI + Oracle Database)

## 🌟 Descripción General del Proyecto

Este proyecto es una aplicación web sencilla para la gestión de citas médicas (CRUD: Crear, Leer, Actualizar, Eliminar). Utiliza la arquitectura de Microservicios con **FastAPI** para el backend y una **Base de Datos Oracle** para el almacenamiento persistente de los datos.

La interfaz de usuario (frontend) es una aplicación de una sola página (SPA) construida con HTML, CSS y JavaScript puro, la cual se comunica con el backend a través de peticiones RESTful.

## 🛠️ Stack Tecnológico

| Componente | Tecnología | Uso |
| :--- | :--- | :--- |
| **Backend (API)** | Python (FastAPI) | Proporciona los *endpoints* REST para las operaciones CRUD. |
| **Base de Datos** | Oracle Database (XE/CDB) | Almacena los datos de las citas y gestiona la secuencia de IDs. |
| **Conexión DB** | `oracledb` (Python) | Driver oficial para la comunicación con Oracle. |
| **Frontend** | HTML, CSS, JavaScript | Interfaz de usuario minimalista para interactuar con la API. |

---

## 📋 Requisitos Previos

Antes de instalar y ejecutar la aplicación, debes tener instalado lo siguiente:

1.  **Python 3.x:** (Recomendado 3.10+)
2.  **Oracle Database:** Debe tener una instancia activa (ej. Oracle XE o una CDB) con un usuario y un servicio accesible (ej. `XEPDB1`).
3.  **Cliente Oracle Instant Client:** Necesario para que el driver `oracledb` se conecte.
4.  **Git:** Para clonar el repositorio.

## ⚙️ Instalación y Configuración

Sigue estos pasos para poner en marcha el proyecto:

### 1. Clonar el Repositorio

```bash
git clone [https://github.com/felipe0afk/Citas_medicas.git](https://github.com/felipe0afk/Citas_medicas.git)
cd Citas_medicas

2. Configurar el Entorno de Python
Crea un entorno virtual y activa las dependencias:
# Crear entorno virtual
python -m venv venv

# Activar el entorno virtual (Windows)
.\venv\Scripts\activate
# Activar el entorno virtual (Linux/macOS)
source venv/bin/activate

# Instalar dependencias
pip install -r requirements.txt
3. Configurar la Base de Datos (Oracle)
Debes crear la tabla y la secuencia necesarias para que la aplicación funcione.

3.1. Crear la Tabla CITAS_MEDICAS
Ejecuta el siguiente script SQL en tu cliente Oracle (como SQL Developer) bajo el esquema de tu usuario (C##CITAS_USER):
CREATE TABLE CITAS_MEDICAS (
    CITA_ID NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY,
    PACIENTE_NOMBRE VARCHAR2(100) NOT NULL,
    FECHA_CITA TIMESTAMP NOT NULL,
    MOTIVO VARCHAR2(255),
    ESTADO VARCHAR2(20) DEFAULT 'Programada' NOT NULL,
    CONSTRAINT PK_CITA PRIMARY KEY (CITA_ID),
    CONSTRAINT CHK_ESTADO CHECK (ESTADO IN ('Programada', 'Completada'))
);

3.2. Configurar la Conexión en database.py
Abre el archivo database.py y asegúrate de que los detalles de conexión coincidan con tu instancia de Oracle:

Python

# Archivo: database.py
DB_USER = "C##CITAS_USER" 
DB_PASS = "CitasPass1" 
DB_HOST = "localhost"
DB_PORT = "1521"
DB_SERVICE = "XEPDB1" # O el nombre de tu PDB/Service


4. Ejecutar el Servidor FastAPI
Una vez configurado, inicia el servidor desde la carpeta raíz del proyecto:
Bash
uvicorn main:app --reload
